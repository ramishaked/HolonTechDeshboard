# דשבורד התמונה החינוכית תשפ"ה

פריסה: להעלות את התיקייה `EducationPicture2025` כמו שהיא ל־GitHub Pages (הכתובת: `.../EducationPicture2025/`).
הדף הוא קובץ אחד (`index.html`) עם הנתונים והגרפים בתוכו, בלי תלות בשרת.

## עיר אחרת
- בדף עצמו: בחירה מרשימת "עיר להצגה", או בכתובת: `.../EducationPicture2025/#c=84004` (סמל רשות).
- מדדי הליבה, ההשוואות והמגמה (תשפ"ב עד תשפ"ה) זמינים לכל 228 הרשויות.
- המדדים הנוספים וההשוואה ללא חינוך מיוחד מוטמעים כרגע לחולון בלבד.
  להוספת עיר: בעמוד https://shkifut.education.gov.il/home להריץ את `fetch-data.js` בקונסול
  (לשנות את `FOCUS`), ולהדביק את הבלוקים בתוך `index.html`.

## נתונים
מקור: משרד החינוך, אתר שקיפות בחינוך, נשלף ב־22.10.2026 (התמונה החינוכית פורסמה ב־21.10.2026).
האתר לא מאפשר טעינה ישירה מדומיין אחר, ולכן הנתונים הם צילום מצב בתוך הקובץ.
