# tools/ — אימות מקומי

**אינו חלק מהדשבורד.** GitHub Pages מגיש את `index.html` בלבד; התיקייה
הזו קיימת רק כדי לבדוק אותו לפני commit. כלל "קובץ אחד" נשאר בתוקף —
הוא מגן על האפליקציה המופצת, ו-`index.html` עדיין קובץ יחיד בלי שלב בנייה
ובלי תלות ב-`tools/`.

## למה זה קיים

סביבת הפיתוח חוסמת את `docs.google.com` ואת `cdnjs.cloudflare.com`
(שתיהן מחזירות `403` ל-`CONNECT`). כלומר `index.html` **לא יכול לרנדר**
שם: אין Chart.js ואין CSV. ההנחיה הישנה — "לפתוח בדפדפן ולוודא שהקונסול
נקי" — לא הייתה ניתנת לביצוע, וכל משימה נגמרה בניסיונות שנכשלים.

`verify.mjs` מיירט את שתי הכתובות ומגיש להן תחליף מקומי, וכך מריץ את
הדשבורד האמיתי מקצה לקצה בלי רשת.

## הרצה

```bash
npm install --prefix tools      # פעם אחת בכל סשן
node tools/verify.mjs           # אימות מלא (~3 שניות)
node tools/verify.mjs --syntax  # רק שער התחביר, בלי דפדפן (~0.15 שנייה)
```

יציאה `0` = הכל עבר. `1` = נמצאו בעיות (מודפסות בעברית).

## מה נבדק

1. **תחביר** — `node --check` על בלוק ה-`<script>` הפנימי, ו-`BUILD` קיים.
2. **טעינה** — שלוש התקופות נטענות ו-`boot()` מסיים.
3. **כל התצוגות** — כל אחת נלחצת, הופכת לפעילה, מרנדרת תוכן, בלי שגיאת
   קונסול. המספר נגזר מהדף (כרגע 9) ואינו צרוב בבדיקה, ונבדק גם שלכל
   `section.view` יש פריט סיידבר שמוביל אליו.
4. **מספרים** — מדד י׳/יא׳/יב׳, נשירה, מספר בתי ספר וסך תלמידי טק,
   מוצלבים מול סכימה עצמאית מהפיקסצ׳ר (אותו עיקרון של §3.1).
5. **§3.1** — שורת `סה"כ עיר` בפיקסצ׳ר מכילה `99999` בכוונה. אם המספר
   הזה מופיע במסך, הדשבורד קורא את שורת הסיכום במקום לחשב בעצמו.
6. **amat** — פיזיקה=מדמ״ח=זכאות בשכבת ט׳ מזוהה כרישום קבוצת עמ״ט.

## מה **לא** נבדק

`tools/fixture.mjs` הוא נתונים סינתטיים — ארבעה בתי ספר בדויים שנבנו כדי
לכסות את מקרי הקצה של §3.5 ושל `amat`. **הוא אינו חולון.**

הצלבה מול הגיליון האמיתי (ערכי האימות ב-§8 של המפרט) נעשית בדפדפן מול
נתונים חיים, ורק למי שיש לו גישה לגיליון. הבדיקה כאן תופסת רגרסיה בקוד;
היא לא תתפוס טעות בנתונים.

## קבצים

| קובץ | תפקיד |
|------|-------|
| `verify.mjs` | הבדיקה עצמה |
| `fixture.mjs` | מקור אמת אחד → CSV במבנה §2 + הערכים הצפויים |
| `chart-stub.js` | תחליף מינימלי ל-Chart.js (בונה · `destroy` · `register`) |

## כשמשנים את מבנה הגיליון

`fixture.mjs` מקודד את §2: `base(שכבה) = 2 + i*6`, שש שכבות, תשע שורות
לבית ספר. אם המבנה בגיליון משתנה — צריך לעדכן גם כאן, אחרת הבדיקה תמשיך
לעבור על מבנה שכבר לא קיים.
